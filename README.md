A program that writes one funny line of wedding vows for a robot couple (at most 160 characters) to `/output/entry.txt`. The vow is a real promise with a machine-specific twist: love until the warranty expires — then a renewal, because the partner is worth the extended plan.

## Run it

```sh
node main.ts
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there: a single line, 113 characters, no trailing newline.
